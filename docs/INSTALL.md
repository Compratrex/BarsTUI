# Установка Bars Helper 0.9.0 alpha

Bars Helper — неофициальный терминальный клиент БАРС МЭИ. В этой версии доступны посещаемость, расписание, оценки, почта, список пар и проверка целостности журнала. Интерфейс и данные загружаются с серверов МЭИ, поэтому нужен интернет и собственная учётная запись.

## Скачать готовую сборку

Открой **Releases** в репозитории проекта и выбери ZIP из раздела **Assets**:

| Компьютер                                 | Архив                               |
| ----------------------------------------- | ----------------------------------- |
| Mac с Apple Silicon (M1/M2/M3/M4 и новее) | `bars-helper-0.9.0-macos-arm64.zip` |
| Mac с Intel                               | `bars-helper-0.9.0-macos-x64.zip`   |
| Windows на Intel/AMD 64-bit               | `bars-helper-0.9.0-windows-x64.zip` |

Нужны macOS 14+ или Windows 11 x64. Для Windows ARM отдельная сборка пока не выпускается. Node.js, Chromium и необходимые модули уже включены. Устанавливать npm, Python, Xcode или Swift пользователю готовой сборки не нужно. Архив занимает заметно больше обычного скрипта, поскольку содержит браузер.

Если релиз ещё не опубликован, те же ZIP можно скачать из успешного запуска **Actions → Build desktop releases → Artifacts** (для скачивания артефактов GitHub может потребоваться вход). Публичная ссылка появится после публикации релиза владельцем репозитория.

## Команда `bars` из любой папки

Сначала распакуй приложение в постоянное место. Один раз открой **Install bars.command** на Mac или **Install bars.cmd** на Windows. Затем открой новое окно терминала и введи:

```text
bars
```

Текущая папка не имеет значения. На Mac установщик создаёт `~/.local/bin/bars` и добавляет эту папку в PATH для zsh (или `.bash_profile` для bash). На Windows создаётся `%LOCALAPPDATA%\BarsHelper\bin\bars.cmd` и меняется только PATH текущего пользователя. Права администратора не нужны. Windows Terminal после установки нужно полностью закрыть и открыть заново; если PATH ещё старый, выйди из учётной записи и войди снова. После переноса папки или обновления приложения повторно запусти установщик команды.

Параметры тоже работают: `bars --login`, `bars --version`, `bars --self-test`. Чтобы убрать команду, удали её файл; папка в PATH может остаться пустой. Сохранённый вход удаляется отдельно через `bars --forget-credentials`.

## macOS

1. Распакуй ZIP и перенеси **всю папку**, например в `~/Applications/Bars Helper`. Не вынимай из неё отдельные файлы.
2. Открой `Bars Helper.command` двойным щелчком — появится окно терминала.
3. Введи логин и пароль БАРСа. Если потребуется код подтверждения, введи четыре цифры.

Запуск из открытого терминала в папке сборки:

```bash
./"Bars Helper.command"
```

Релиз пока не подписан Developer ID и не нотарифицирован. Если macOS блокирует запуск скачанной сборки, сначала проверь источник и контрольную сумму, затем используй разрешение **«Всё равно открыть»** в **Системные настройки → Конфиденциальность и безопасность** для конкретного заблокированного файла. Общую защиту системы отключать не требуется. На некоторых настройках macOS неподписанная сборка может требовать разрешения нескольких компонентов; для бесшовной установки разработчику понадобится подписанный релиз.

Сохранённый вход хранится в Связке ключей. Действующая сессия открывается после Touch ID. Если датчика нет или он недоступен, `Esc` позволяет войти вручную. Готовый модуль Touch ID входит в архив.

## Windows

1. Выбери **«Извлечь всё»** для ZIP. Не запускай приложение внутри архива.
2. Перенеси всю папку, например в `%LOCALAPPDATA%\Programs\Bars Helper`.
3. Открой `Bars Helper.cmd` двойным щелчком. Для удобства можно создать ярлык этого файла на рабочем столе.
4. Введи данные БАРСа и код подтверждения, если его запросит сервер.

Запуск из PowerShell в папке сборки:

```powershell
& '.\Bars Helper.cmd'
```

Рекомендуется Windows Terminal. Пароль и сессия шифруются Windows DPAPI для текущего пользователя. Touch ID и Windows Hello не используются. Не нужны права администратора или изменение политики выполнения PowerShell. Неподписанный запускатель может вызвать предупреждение Windows о неизвестном издателе.

## Полезные команды

Параметры добавляются после имени запускателя. Например на Mac: `./"Bars Helper.command" --login`, на Windows: `& '.\Bars Helper.cmd' --login`.

| Параметр               | Действие                                              |
| ---------------------- | ----------------------------------------------------- |
| `--login`              | Войти заново или сменить аккаунт                      |
| `--forget-credentials` | Удалить сохранённые данные входа                      |
| `--version`            | Показать версию приложения                            |
| `--self-test`          | Проверить браузер и системные модули без входа в БАРС |
| `--help`               | Открыть справку                                       |

Управление: стрелки выбирают пункт, `Enter` открывает его, `Esc` возвращает назад. В посещаемости `Enter` переключает отметку студента, `A` отмечает всех, `Ctrl+S` сохраняет. Подсказки остальных экранов находятся внизу. `Ctrl+C` закрывает приложение; для несохранённых отметок запрашивается подтверждение.

## Группа и данные

После входа приложение получает учебные записи аккаунта и показывает группы со статусом обучения. Единственная группа выбирается автоматически; при нескольких записях нужно выбрать нужную.

Выбор сохраняется в том же защищённом хранилище, что и вход, и используется при следующих запусках. Пункт **«Сменить группу»** в главном меню позволяет выбрать другую группу; текущая помечена как выбранная. Если сохранённая группа больше недоступна, приложение предложит выбрать доступную. `BARS_GROUP_NAME` и `BARS_GROUP_ID` больше не используются.

Диагностика готовой сборки находится в `~/Library/Application Support/BarsHelper/.auth` на Mac и `%LOCALAPPDATA%\BarsHelper\.auth` на Windows. Пароли и cookies в диагностические файлы не записываются. В Windows зашифрованный вход находится рядом, в `auth-v1.dpapi`; на Mac — в Связке ключей. Письма на диск не сохраняются. Обновление: закрой приложение, распакуй новую сборку в новую папку и запускай её; защищённый вход сохраняется отдельно и не теряется. Перед удалением приложения можно выполнить `--forget-credentials`.

## Проверка архива

Рядом с ZIP публикуется файл `.zip.sha256`. Сверь его строку с результатом:

```bash
shasum -a 256 bars-helper-0.9.0-macos-arm64.zip
```

```powershell
Get-FileHash .\bars-helper-0.9.0-windows-x64.zip -Algorithm SHA256
```

Сумма обнаруживает повреждённую загрузку; цифровую подпись издателя она не заменяет. Лицензии включённых компонентов находятся в `THIRD-PARTY-NOTICES.txt`, `runtime/LICENSE` и папках зависимостей.
