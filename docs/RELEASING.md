# Сборка и выпуск

## Из исходников

Нужен Node.js 22.x и npm. Открой корень проекта в WebStorm как обычный Node.js/TypeScript-проект.

```bash
npm ci
npx playwright install --only-shell chromium
npm run build
```

После сборки запускай `Bars Helper.command` на Mac или `Bars Helper.cmd` на Windows. `npm start` остаётся режимом разработки. `npm run start:built` запускает уже скомпилированный код. Для команды `bars` из любого каталога один раз выполни `npm run command:install` и открой новое окно терминала. Команда запускает `dist/`, поэтому после изменений исходников выполняй `npm run build`. Альтернатива — `npm link`, если глобальная папка npm доступна твоему пользователю.

## Самостоятельный архив

```bash
npm run release:build
```

Скрипт создаёт папку, ZIP и SHA-256 в `release/`. Сборка **нативная**: Mac arm64 создаёт macOS arm64, Intel Mac — macOS x64, Windows x64 — Windows x64. Кросс-сборка заменой имени архива не поддерживается. На Mac сборщику нужны Command Line Tools (`xcode-select --install`), конечному пользователю — нет.

В архив включаются скомпилированный JavaScript, production-зависимости из `package-lock.json`, официальный Node.js 22, Chromium Headless Shell, запускатель и нативные модули. Node.js скачивается с nodejs.org и проверяется по `SHASUMS256.txt`. По умолчанию берётся последний 22.x; точная версия и контрольная сумма записываются в `release-info.json`. Для повторяемой сборки можно указать `BARS_RELEASE_NODE_VERSION=22.x.y`, подставив версию из этого файла. Зависимости npm и браузер зафиксированы lock-файлом. Загрузка требует интернета.

Входные файлы копируются по явному списку. `.auth`, `.cache`, `.env`, `.git`, исходники тестов и личные скрипты в архив не попадают. Не архивируй рабочую папку целиком вручную. Самопроверка запускает браузер на локальной тестовой странице и проверяет нативный модуль без реального аккаунта и без запроса отпечатка.
