Bars Helper 0.9.0 alpha — неофициальный терминальный клиент БАРС МЭИ.

- Посещаемость, расписание, оценки, почта и список занятий.
- Проверка целостности расписания и журнала, исправление доступных нарушений.
- Сохранение входа: Связка ключей и Touch ID на macOS; DPAPI на Windows.
- Готовые архивы для macOS arm64, macOS Intel и Windows x64. Node.js и браузер включены.

Для запуска командой `bars` из любой папки один раз открой `Install bars.command` (Mac) или `Install bars.cmd` (Windows), затем открой новый терминал.

Распакуй **всю папку** и запусти `Bars Helper.command` на Mac или `Bars Helper.cmd` на Windows. Инструкция находится внутри архива: `docs/INSTALL.md`. Нужны macOS 14+ или Windows 11 x64. Группы определяются по учебным записям аккаунта. Выбор сохраняется между запусками; сменить группу можно в главном меню.

Это предварительная версия. Архивы пока без подписи издателя; система может запросить разрешение на запуск. Вместе с архивами приложены контрольные суммы SHA-256.
