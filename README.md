# Bars Helper

Неофициальный терминальный клиент БАРС МЭИ для macOS и Windows.

Отмечайте посещаемость, просматривайте расписание, оценки и университетскую почту прямо в терминале.

[Установка](docs/INSTALL.md) · [Архитектура проекта](docs/ARCHITECTURE.md) · [Сборка и выпуск релизов](docs/RELEASING.md)

## Возможности

### Посещаемость

Отметка посещаемости студентов на текущей или выбранной паре. Приложение находит текущее занятие по московскому времени и загружает список студентов. Можно отметить присутствующих по одному или всей группой, изменить существующие отметки и создать запись для занятия, которого ещё нет в журнале.

Черновики сохраняются при переходах между парами до выхода из приложения. Перед отправкой проверяются изменения на сервере, после сохранения — результат. Редактирование доступно в пределах прав пользователя в БАРСе.

### Расписание

Недельное расписание группы с понедельника по воскресенье. Для каждого занятия показаны предмет, время, номер пары, тип, аудитория и преподаватель, если эти данные доступны в БАРСе.

Доступны просмотр предыдущих и следующих недель, возврат к текущей неделе и обновление данных.

### Оценки

Личная успеваемость вошедшего студента в таблице по дисциплинам и неделям обучения.

### Почта

Просмотр входящих и чтение писем университетской почты МЭИ. Используются логин и пароль текущего аккаунта БАРСа — отдельно вводить данные почты не требуется.

Открытие письма помечает его прочитанным. Отправка, удаление и перемещение писем пока не реализованы; просмотр и скачивание вложений доступны в веб-почте. Тексты писем и почтовая сессия на диск не сохраняются.

### Все пары

Общий список занятий семестра из расписания и журнала, сгруппированный по датам. Для каждой пары доступны предмет, время, номер, тип и статус: на рассмотрении, требуется корректировка, согласовано или нет записи в журнале. Из списка можно перейти к посещаемости выбранной пары.

### Проверка целостности

Сверка расписания с записями старосты в журнале по предмету, дате, времени, номеру пары и типу занятия. Для каждой пары определяется результат:

- **Норма** — запись соответствует расписанию.
- **Нарушение** — поля не совпадают, найдены дубли, лишняя запись или отсутствует запись для уже закончившейся пары.
- **Ещё не прошла** — записи пока нет, а пара ещё не закончилась.

Для нарушения можно открыть подробное объяснение. Статус согласования записи сам по себе не считается нарушением целостности.

Доступно автоматическое исправление типа, времени и номера пары у однозначно найденных редактируемых записей. Отметки студентов и остальные поля сохраняются. После исправления выполняется повторная сверка.

Для отсутствующей записи можно перейти в посещаемость и указать присутствующих вручную. Дубли и неоднозначные соответствия требуют ручной проверки в БАРСе. При ошибке очередь останавливается без автоматической повторной отправки.

### Выбор группы

Если у студента одна группа, она выбирается автоматически. Если несколько — доступны выбор группы и её статус обучения. Выбор сохраняется вместе с данными входа и используется при следующих запусках; сменить группу можно из главного меню.

Расписание, журнал посещаемости и оценки относятся к выбранной учебной записи. Черновики отметок разных групп хранятся отдельно до выхода из приложения.

## Установка и запуск

Для работы нужны интернет, учётная запись МЭИ и доступ к соответствующим разделам БАРСа. Группы определяются по учебным записям вошедшего студента.

Команда работает из любой папки. Приложение также можно открыть напрямую через `Bars Helper.command` или `Bars Helper.cmd`.

Выбор архива, требования к системе и обновление описаны в [руководстве для macOS и Windows](docs/INSTALL.md).

## Вход и сохранённая сессия

Вход по логину и паролю БАРСа с поддержкой двухфакторной аутентификации.

После успешного входа приложение сохраняет данные в защищённом хранилище:

- **macOS:** Связка ключей. При повторном запуске сначала проверяется сессия, затем доступ к действующей сессии подтверждается через Touch ID.
- **Windows:** системное шифрование DPAPI для текущего пользователя, без запроса биометрии.

Действующая сессия используется повторно. Если она истекла, приложение выполняет вход с сохранёнными данными и при необходимости запрашивает новый код. Поддерживаются ручной вход, смена аккаунта и удаление сохранённых данных.

## Разработка

Стек: **TypeScript, React, Ink и Playwright**. Для запуска из исходников нужен Node.js 22 или новее.

Из папки проекта:

```bash
npm ci
npx playwright install --only-shell chromium
npm start
```

В PowerShell при необходимости используйте `npm.cmd` и `npx.cmd`. На macOS для первой сборки модуля Touch ID из исходников нужны Command Line Tools (`xcode-select --install`); пользователю готового архива они не требуются.

Чтобы запускать свою сборку командой `bars`:

```bash
npm run build
npm run command:install
```

После установки откройте новый терминал. `npm start` запускает исходники, а `bars` — собранную версию: после изменения кода нужно повторить `npm run build`.

Проверки и форматирование:

```bash
npm run format
npm run format:check
npm run typecheck
npm test
npm run test:integration
```

Интеграционные тесты используют локальный сервер и Chromium, без изменения настоящих журналов. Структура папок и правила зависимостей описаны в [документации по архитектуре](docs/ARCHITECTURE.md).

Переносимый архив для текущей платформы собирается командой `npm run release:build`. Подготовка сборок macOS arm64, macOS Intel и Windows x64 описана в [руководстве по выпуску релизов](docs/RELEASING.md).

### Служебные команды

В проекте остаются отдельные скрипты для работы с журналом:

- `npm run login` открывает браузер для ручного входа и сохраняет сессию в `.auth/bars-storage.json`. Это отдельная сессия служебных скриптов, она не нужна для обычного запуска TUI.
- `npm run journals` предлагает выбрать группу и журнал, сверяет его с расписанием и запрашивает подтверждение перед изменениями. У этого скрипта собственные правила автоматического заполнения; основной интерфейс приложения запускается через `bars` или `npm start`.
